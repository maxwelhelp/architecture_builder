# Reports

Keep lightweight summaries here, not full run directories.

Allowed:
- small JSON summaries
- CSV metrics tables
- Markdown analysis notes
- architecture memory extracts

Do not commit full runs, checkpoints, datasets, audio files, or huge zip archives.

Recommended naming:
- reports/v13_15ep_summary.md
- reports/v13_15ep_metrics.csv
- reports/architecture_memory.jsonl
